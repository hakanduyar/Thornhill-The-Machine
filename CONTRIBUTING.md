# Contributing

Use issues for a concise problem statement, reproduction steps, browser/device and expected behavior. Include a screenshot or short recording when it clarifies a visual issue; remove personal or sensitive content first.

Keep changes focused and preserve the existing scene and controls unless the issue explicitly changes them. Run `pnpm test`, `pnpm typecheck` and `pnpm build` before proposing a change. State which browser interactions you actually observed; do not label simulated tests as visual verification.

Do not commit credentials, environment files, private prompts, local logs, caches or personal paths. Add only assets you have permission to share and document their provenance. Accurately disclose significant generated media or tool-assisted contributions. Attribution must reflect real work; do not add invented contributor identities or history.
